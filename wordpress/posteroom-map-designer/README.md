# Posteroom Map Designer — εγκατάσταση

Το ZIP εγκαθίσταται ως WordPress plugin. Περιλαμβάνει τον designer, τη σύνδεση WooCommerce, τα αρχεία build και τον αντίστοιχο πηγαίο κώδικα. Δεν αντικαθιστά τον AI generator και δεν χρησιμοποιεί FAL ή API key.

## Πριν από την εγκατάσταση

- Κράτησε backup και κάνε πρώτα δοκιμή σε staging. Απαιτούνται WordPress 6.5+, PHP 8.1+, WooCommerce και GD ή Imagick με υποστήριξη PNG. Για thumbnails στα Cart/Checkout Blocks απαιτείται WooCommerce 9.6+.
- Στο υπάρχον **Snippet 2**, το τελευταίο `woocommerce_admin_order_item_thumbnail` filter έχει δύο παραμέτρους στη συνάρτηση αλλά δηλώνει ένα όρισμα. Άλλαξε ΜΟΝΟ το τελευταίο `}, 10, 1);` σε `}, 10, 2);`, διαφορετικά η προβολή παραγγελίας μπορεί να εμφανίσει PHP error.
- Το παλιό AI snippet επιτρέπει τιμή από τον browser. Το νέο plugin δεν το χρησιμοποιεί: οι χάρτες παίρνουν την πραγματική τιμή της παραλλαγής. Η διόρθωση της τιμολόγησης του AI generator είναι ξεχωριστή αλλαγή στο υπάρχον snippet.

## Βήματα

1. Πρόσθετα → Νέο πρόσθετο → Μεταφόρτωση προσθέτου → επίλεξε `posteroom-map-designer.zip` → Εγκατάσταση → Ενεργοποίηση.
2. WooCommerce → **Posteroom Maps**. Οι αρχικές αντιστοιχίσεις είναι A3: `4249`, A4: `4250`, όπως στο υπάρχον snippet. Επιβεβαίωσε τα ονόματα και τις τιμές που εμφανίζονται. Portrait και landscape χρησιμοποιούν την ίδια παραλλαγή ανά μέγεθος.
3. Έλεγξε το **Private artwork directory**. Πρέπει να είναι εγγράψιμος φάκελος εκτός `public_html` / web root. Η αρχική τιμή προτείνει τον διπλανό φάκελο `posteroom-artwork`. Αν εμφανιστεί προειδοποίηση, χρειάζεται σωστή διαδρομή από το hosting. Μην τον βάλεις στα δημόσια uploads. Πρόσθεσέ τον στο backup του καταστήματος.
4. Ενεργοποίησε **Enable map orders** και αποθήκευσε.
5. Στη σελίδα Terra Ink του Elementor, χρησιμοποίησε πλάτος πλήρους σελίδας, αφαίρεσε περιττό padding από το container και πρόσθεσε widget **Shortcode** με:

```text
[posteroom_map_designer]
```

6. Καθάρισε την cache της συγκεκριμένης σελίδας. Εξαίρεσε το script `posteroom-map-designer` από εργαλεία που το συνδυάζουν ή αλλάζουν το `type="module"`. Μην αντιγράψεις το `sw.js` του παλιού standalone ZIP στο WordPress root.
7. Κάνε μία δοκιμαστική αγορά A4 και μία A3, έλεγξε thumbnail, τιμή, orientation, μεταφορικά και παραγγελία. Στη διαχείριση της παραγγελίας θα υπάρχει **Download print PNG** σε κάθε χάρτη.

## Συμπεριφορά και όρια

- Η τελική τιμή, ο ΦΠΑ, οι εκπτώσεις, το stock και τα μεταφορικά υπολογίζονται από το WooCommerce. Τα ποσά του παλιού HTML δεν αντιγράφονται ως τιμές στο νέο plugin.
- Το PNG παράγεται στον browser στα 300 DPI και ανεβαίνει στο κατάστημα. Τα A4 είναι 2480×3508 και τα A3 3508×4961 pixels, με εναλλαγή διαστάσεων για landscape.
- Το αρχείο εκτύπωσης αποθηκεύεται εκτός web root. Το μικρό JPEG preview διαθέτει υπογεγραμμένο σύνδεσμο και μπορεί να προβληθεί από όποιον έχει αυτόν τον σύνδεσμο. Η λήψη του πρωτοτύπου απαιτεί λογαριασμό με `manage_woocommerce` και έγκυρο nonce.
- Επειδή η παραγωγή του PNG γίνεται στον browser, ο πελάτης μπορεί τεχνικά να προσπελάσει το αρχείο κατά τη δημιουργία. Η προστατευμένη αποθήκευση αφορά το αντίγραφο του server.
- Επιτρέπονται μέχρι 32 MB ανά PNG και δέκα διαφορετικά map designs στο καλάθι. Ρύθμισε `upload_max_filesize` τουλάχιστον 32 MB, `post_max_size` μεγαλύτερο από 32 MB και `memory_limit` τουλάχιστον 256 MB.
- Αρχεία χωρίς παραγγελία διαγράφονται μετά από επτά ημέρες μέσω WP-Cron. Τα αρχεία παραγγελιών παραμένουν. Ένα ληγμένο artwork εμποδίζει το checkout και πρέπει να δημιουργηθεί ξανά.
- Η ίδια επανάληψη αιτήματος δεν αυξάνει την ποσότητα. Διαφορετικά σχέδια παραμένουν ξεχωριστές γραμμές.
- Μία εμφάνιση shortcode ανά σελίδα. Ο designer χρησιμοποιεί Shadow DOM για απομόνωση CSS και δεν εγκαθιστά service worker μέσα στο WordPress.
- Οι αλλαγές στο plugin δεν ενεργοποιούν το καλάθι στο ανεξάρτητο Sites preview. Η αγορά λειτουργεί στη σελίδα του ίδιου του καταστήματος.
